# Trang web BS. Hà Hiếu

- `index.html`: giao diện trang (không cần sửa).
- `data.js`: thông tin phòng khám, bảng giá công khai, bài viết. Anh chỉ sửa tệp này.

Trang Tính tiền mở bằng link "Khu bác sĩ" ở cuối trang (hoặc thêm `#tinh-tien` vào cuối địa chỉ).
Dữ liệu tính tiền chỉ lưu trên trình duyệt của máy đang dùng, không đưa lên GitHub. Nhớ sao lưu hằng tuần.
